# Vertical Science Studio — interface gratuite

Interface statique, utilisable depuis Android. Sélectionnez un thème ou une actualité datée.
Le rendu MP4 s'effectue sur GitHub Actions, pas sur Hugging Face.

Source : https://github.com/dbrckk/Production-vid-o-verticale-

Aucune donnée d'authentification GitHub n'est stockée par ce Space.
Les éventuels jetons sont conservés uniquement dans la mémoire de l'onglet et transmis directement à api.github.com.
Les actualités sont exportées périodiquement à partir de flux RSS publics, sans invention de sources.
